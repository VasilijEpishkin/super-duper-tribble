# ALTAR’ — success criteria v0.1

Planning criteria; they become release gates after the owner confirms the order path, stack and content.

## Content and shopping

- [ ] Before page-map approval, the owner has chosen the order path for ready-made products and custom work; product actions, data ownership, hosting and any payment/form provider are specified.
- [ ] Brand claims, audience and current packaging have been checked against the [source audit](docs/BRAND_SOURCE_AUDIT.md); archived products are not silently added.
- [ ] All 18 currently listed positions, including the gift certificate, are accounted for in a product/asset map; each has verified name, current price, image, relevant options and order action.
- [ ] Home and product pages make the next action clear on desktop and mobile.
- [ ] Custom-order path explains what to send, how the process works and where the request goes.
- [ ] Contact details, care, warranty, delivery/payment/returns and privacy wording are approved by the brand owner.
- [ ] Old public URLs have working redirects or retained paths, including both existing product URL patterns.

## Visual and media

- [ ] Screens match the approved direction and brandbook palette; original ALTAR assets are used, third-party references are not shipped.
- [ ] Product imagery preserves jewelry color/detail and supports zoom or close inspection.
- [ ] Any video has a poster/fallback, mobile crop, muted autoplay only where appropriate and reduced-motion behavior.
- [ ] Web fonts render Cyrillic and remain readable at small sizes.

## Runtime evidence before release

- [ ] Real browser checks cover desktop and mobile navigation, catalog, every product template, custom order and the agreed checkout flow.
- [ ] No blocker/high issues in accessibility, broken links, forms, console/network errors or visual finish.
- [ ] Core pages meet an agreed performance budget with optimized images/video; budget is set after selecting the stack and media.
- [ ] The new order path is verified end to end before the live site is replaced.
