# Design Tokens

Source: Stitch Molten Relic Brutalism. Values are starting points; confirm contrast in actual UI.

## Color
- Background: #000000 (void); Stitch surface #131313
- Surface: #1B1B1B
- Elevated surface: #2C1900 (raw earth; use sparingly)
- Text: #FFFFFF; secondary text #E2E2E2
- Border: #5B403C or restrained silver #D8D8D8
- Accent: #9C0000; hover #BE0D0D
- Metallic highlight: #D8D8D8 / #E5E5E5

## Typography
- Display/headings/labels: Courier Prime
- Body: Geist
- Display scale: 56/64 desktop; 38/44 mobile
- Body: 16/26 large; 14/22 standard; 12/18 small
- Labels: 9–13px, uppercase and wide tracked

## Spacing and shape
- Desktop margin/gutter: 3rem / 1.5rem
- Mobile margin/gutter: 1.25rem / 0.75rem
- Scale: 0.25rem, 0.5rem, 1rem, 2rem, 4rem
- Corner radius: 0
- Depth: Tonal surfaces and hairline borders; avoid conventional drop shadows.

## Breakpoints
- Desktop grid: 12 columns
- Mobile grid: 4 columns
- Tablet breakpoint: To be defined during implementation.
