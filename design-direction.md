# ALTAR’ website — visual direction proposal

Status: The user approved the light “Editorial Mineral” homepage and requested a built preview.

## Source constraints
Miro describes a woman whose strength is self-possessed, whose softness has inner support, and whose personal symbol can mean something different to each wearer. It explicitly rejects demonstrative luxury. Use the existing Miro and Stitch photographs as the visual source. Do not reproduce literal occult imagery, a witch/goddess character, aggression, or overt sexuality. The current Stitch system provides a dark editorial foundation, but its “ritual/erotic” wording is not an instruction for the storefront.

## Direction — Editorial Mineral
Warm mineral-white canvas, stone surfaces, charcoal type, and a restrained oxblood action color. EB Garamond display paired with Geist interface text. Large real product photography and close material details lead; concise Russian product facts remain easy to scan. Asymmetrical editorial rhythm, hairline dividers, sharp frames, restrained transitions.

Use the user-approved Stitch screen “ALTAR’ — Главная страница (Editorial Mineral)” and system “ALTAR Editorial — Mineral” as the implementation reference. Product facts stay first-class; use oxblood sparingly; exclude decorative occult/religious symbols and invented jewelry photography or claims. Use the Stitch project's existing source photos. This first implementation is a visual homepage prototype, not a functioning commerce system.

## Interaction principles
- Navigation and cart stay immediately discoverable.
- Product price, sizes, material facts, and purchase action are clear without scrolling past long brand copy.
- Keep custom-order contact distinct from ready-to-buy checkout.
- Use motion only to clarify image/story transitions; respect reduced motion.
