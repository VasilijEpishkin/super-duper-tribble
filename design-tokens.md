# ALTAR’ — provisional design tokens

Status: approved by the user with the Stitch homepage screen “Editorial Mineral”.

## Color
- Canvas: warm mineral `#F7F4EE`.
- Surface: pale stone `#F3F1EC`; divider `#E8E5DF`.
- Main text: charcoal `#1C1B1A`; secondary text `#77736D`.
- Accent: oxblood `#8C2E24`, used sparingly for meaningful actions and markers.

## Typography
- Display headings: EB Garamond.
- Body and product facts: Geist.
- Preserve generous body line-height; do not set critical product information in tiny tracked labels.

## Layout / shape
- Use a spacious editorial desktop grid and a clear 4-column mobile grid.
- Sharp frames and hairline rules; use whitespace and tonal layering for depth.
- Breakpoints, image ratios, contrast, and focus styles are to be validated in the first approved screens.
